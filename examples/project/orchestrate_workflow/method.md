# Привязка проекта

Общие навыки установлены отдельно. Этот файл содержит только локальные пути и отклонения; протокол и формы ролей определены в их `SKILL.md`.

## Пути

| Назначение | Путь |
|---|---|
| Контракт | `AGENTS.md` |
| Очередь и задачи | `orchestrate_workflow/plans/<план>/` |
| Исполнение и отчёты | `orchestrate_workflow/<план>/` |

Очередь и материалы задач находятся в Git. Каталог активной сессии исключается из Git по конкретному пути в `.git/info/exclude`.

## Предметный контракт

Определяется `AGENTS.md` целевого проекта и критериями текущей задачи.

## Профили и ограничения

По общему протоколу; конкретные модели не закреплены.

## Формат отчёта

По общему протоколу.
