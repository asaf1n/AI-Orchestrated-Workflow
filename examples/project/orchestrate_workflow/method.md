# Привязка проекта

Навыки `planner`, `orchestrate`, `implementer`, `reviewer` установлены в общем профиле и вызываются по имени. Документы процесса находятся внутри проекта. Нормативный протокол — `references/protocol.md` относительно привязки `orchestrate_workflow/method.md`; формы состояния, начало и восстановление сессии, шаблоны обмена находятся в том же каталоге: `runtimes.md`, `session-start.md`, `templates.md`.

Этот файл оркестратор создаёт и адаптирует при подготовке проекта по project-files.md проектного комплекта. Он задаёт только пути и проектные отклонения. Общие правила ролей, запуска, ревью, приёмки и восстановления здесь не повторяются. Документы процесса находятся внутри проекта; ссылки на профиль пользователя не создаются. Если проектный комплект неполон, назови отсутствующий путь и не восстанавливай процесс по старым отчётам.

## Пути проекта

| Назначение | Место |
|---|---|
| Контракт проекта | `AGENTS.md` |
| Корень workflow | `orchestrate_workflow/` |
| Очередь и статус плана | `orchestrate_workflow/plans/<план>/00_summary.md` |
| Материал задачи и состояние этапов | `orchestrate_workflow/plans/<план>/<задача>.md` |
| Действующее задание | `orchestrate_workflow/<план>/spec.md` |
| Отчёт исполнителя | `orchestrate_workflow/<план>/result.md` |
| Независимое ревью | `orchestrate_workflow/<план>/review.md` |

`orchestrate_workflow/plans/` хранится в git. Каталог текущей сессии `orchestrate_workflow/<план>/` локальный и исключается по точному пути `/orchestrate_workflow/<план>/` через `.git/info/exclude`. Имя `plans` зарезервировано и не используется как имя плана.

Файлы выбираются только по точным путям и явным ссылкам. Task-файлами считаются только файлы, на которые ссылается `00_summary.md`. В каталоге текущей сессии протокольными являются только `spec.md`, `result.md`, `review.md`; другие локальные файлы читаются только при явной ссылке из материала задачи, задания или общего протокола.

## Проектные отклонения

Нет. Предметные источники, допустимые изменения и проверки определяет `AGENTS.md` и текущее задание этапа.
