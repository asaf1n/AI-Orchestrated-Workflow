Используй установленный навык `orchestrate`. Если установленный навык недоступен для чтения, назови путь и остановись; процесс по привязке и прежним отчётам не восстанавливай. Прочитай `orchestrate_workflow/method.md` и `AGENTS.md` этого проекта. Общие правила и ресурсы читай из установленного навыка; проектная привязка задаёт пути и отклонения.

Не создавай отдельный локальный план и копии заданий. На старте сверь материал задачи, git и каталог текущей сессии по началу сессии из установленного навыка `orchestrate`. Если запрошен статус, исполнение не запускай. Роли implementer и reviewer получай новым контекстом; поставщика и модель роли выбирай по общему протоколу. Принадлежность файлов из контракта сохраняется.
