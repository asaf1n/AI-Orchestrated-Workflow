# Установка и обновление

Источник истины — содержимое `skills/` этого репозитория. До обновления сверь HEAD, рабочее дерево и установленные пути; не перезаписывай пользовательские дополнения. Изменённый комплект должен пройти независимое ревью окончательной версии.

Установи четыре каталога навыков в обнаруживаемый runtime путь. Для Antigravity App/IDE и CLI используй общий `~/.gemini/config/skills/`, не создавая параллельной установленной копии. Если другой каталог уже содержит навык того же имени, установи фактический приоритет через runtime и устрани рассинхронизацию только после проверки содержимого и прав.

Сверь SHA-256 установленной версии с исходником и выполни реальный вызов на чтение без модификаций. Последующие задачи запускай в новом контексте. Изменение комплекта не запускает и не принимает продуктовые этапы.

Снимок изменённого рабочего дерева можно получить через [snapshot.py](../scripts/snapshot.py); он не проверяет игнорируемые файлы, submodules и внешние сервисы.
