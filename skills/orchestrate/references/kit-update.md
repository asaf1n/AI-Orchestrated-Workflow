# Установка и обновление навыков

Источник — `skills/` этого репозитория. Устанавливай только необходимые навыки в фактический каталог обнаружения runtime:

- Codex / общий: `~/.agents/skills/` (или используемый каталог профиля).
- Claude Code: `~/.claude/skills/` или `$CLAUDE_CONFIG_DIR/skills/`.
- Antigravity: `~/.gemini/config/skills/` для App, IDE и agy.

Не создавай лишних копий. Перед заменой сравни файлы и сохрани пользовательские дополнения. Обновляй `SKILL.md` и соответствующие изменённые `references/`; удаляй устаревшие файлы только при известном происхождении.

Определения ролей (`agents/`) и глобальные `AGENTS.md`/`CLAUDE.md`/`GEMINI.md` изменяй **только** по отдельному поручению. Проектный `AGENTS.md` не заменяет глобальный.

После установки убедись, что нужный навык обнаруживается runtime, и при необходимости проверь одну его реальную функцию. Сплошные SHA-256, обязательное независимое ревью установки, искусственный тест изоляции после каждого обновления и повторная установка во все аккаунты не требуются. При проблеме сравни конкретные файлы и каталоги.
