# Установка и обновление

Источник истины — содержимое `skills/` этого репозитория. До обновления сверь HEAD, рабочее дерево и установленные пути; не перезаписывай пользовательские дополнения. Изменённый комплект должен пройти независимое ревью окончательной версии.

Установи четыре каталога навыков в обнаруживаемый runtime путь. Для Antigravity App/IDE и CLI используй общий `~/.gemini/config/skills/`, не создавая параллельной установленной копии. Если другой каталог уже содержит навык того же имени, установи фактический приоритет через runtime и устрани рассинхронизацию только после проверки содержимого и прав.

Переноси проверенные `SKILL.md`, `references/` и изменённые помощники, сохраняя пользовательские `agents/openai.yaml` и настройки. Простое копирование не удаляет устаревшие файлы: удаляй их только в границах поручения после проверки абсолютных путей и всех ссылок.

При порученном обновлении определений ролей сравни `~/.claude/agents/` и `~/.codex/agents/` с соответствующими `examples/`, сохрани пользовательские и проектные отличия. Определения Antigravity переноси только в проверенный каталог обнаружения; наличие примера не подтверждает поддержку runtime.

Глобальные инструкции обновляй только по отдельному поручению. Для синхронизации общего контракта сопоставь `~/AGENTS.md`, `~/.agents/AGENTS.md`, `~/.codex/AGENTS.md`, `~/.claude/CLAUDE.md` и `~/.gemini/GEMINI.md`; согласуй содержательные отличия в окончательной версии до независимого ревью, затем перенеси её и сверь SHA-256 каждой копии. Эти файлы не заменяются проектным `AGENTS.md` репозитория. Проектные `CLAUDE.md` и `GEMINI.md` остаются маршрутами `@AGENTS.md`; общий контракт не распространяется на остальные проекты без поручения.

Сверь SHA-256 установленной версии с исходником и выполни реальный вызов на чтение без модификаций, включая контрольный вызов изоляции контекста по [external-calls.md](external-calls.md). Последующие задачи запускай в новом контексте. Изменение комплекта не запускает и не принимает продуктовые этапы.

Снимок изменённого рабочего дерева можно получить через [snapshot.py](../scripts/snapshot.py); он не проверяет игнорируемые файлы, submodules и внешние сервисы.
