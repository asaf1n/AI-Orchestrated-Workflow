# Обновление комплекта

Справочный материал оркестратора; читается по ссылке из [SKILL.md](../SKILL.md). Роли planner, implementer и reviewer эти файлы не читают.

Исходный Git-репозиторий навыков — источник истины. До изменения проверь его фактический путь, remote, HEAD, origin/main и рабочее дерево; установленную копию сравнивай с актуальными исходниками, сохраняя локальные дополнения. Изменения всех четырёх навыков, форм и затронутых привязок проходят независимое ревью точной версии до установки.

После положительного ревью перенеси проверенные файлы в фактические каталоги обнаружения runtime, сохрани пользовательские agents/openai.yaml и другие настройки. Запрещено создавать несанкционированные подпапки синхронизации и бэкапов (`.trash/`, `synced/`, `*.tmp`, `*.bak`) в дереве навыков. Удаляй только проверенные устаревшие файлы в границах поручения; прежде проверь абсолютные пути и всех вызывающих. Сверь SHA-256 содержимого после установки и повторного переноса. Уже запущенные сессии могут содержать прежние инструкции: для следующего вызова используй новый контекст и проверь путь загруженного SKILL.md. Обрыв ревью не разрешает распространение комплекта.

Для сверки Git-рабочего дерева можно использовать [snapshot.py](../scripts/snapshot.py): он читает HEAD, diff, индекс и содержимое изменённых/неотслеживаемых файлов. Игнорируемые файлы, submodules и внешние сервисы его снимком не покрываются; spec/result/review и состояние БД проверяются отдельно.
