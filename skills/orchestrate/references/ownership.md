# Владение изменениями

- Orchestrator отвечает за объединение результата; Planner — за порученный план, Implementer — за порученную реализацию, Reviewer — за заключение на чтение. Простые изменения Orchestrator может выполнять напрямую.
- Перед записью учитывай существующие незакоммиченные изменения и принадлежность файлов. Не затирай и не коммить чужое.
- Коммиты делай в разрешённой ветке, в содержательных границах изменений. Один коммит на каждый этап **не обязателен**.
- Push и merge выполняются только по условиям целевого проекта и разрешению пользователя.
- Перед повтором потенциально необратимой операции проверь её реальные последствия; отсутствие отчёта не означает отсутствие результата.

Для передачи сессии достаточно указать текущую ветку/коммит при наличии, изменённые файлы, незавершённое действие и блокер. Обязательных снимков SHA-256 нет.
