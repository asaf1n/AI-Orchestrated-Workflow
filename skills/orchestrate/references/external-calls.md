# Внешние вызовы и запуск ролей

Справочный материал оркестратора; читается по ссылке из [SKILL.md](../SKILL.md). Роли planner, implementer и reviewer эти файлы не читают.

## Выбор способа запуска роли

По умолчанию роль запускает встроенный субагент runtime: определение из `.claude/agents` или `.codex/agents`, `invoke_subagent` в Antigravity. Он даёт новый контекст и модель сессии при общем workspace. Внешний неинтерактивный CLI нужен, когда критерий требует конкретную модель или поставщика, недоступных в текущей сессии, независимый канал квоты, либо runtime не поддерживает субагентов. Причину внешнего вызова укажи в spec.md.

## Внешние вызовы

Используй отдельный неинтерактивный запуск в корне проекта. В промпте назови точный SKILL.md роли, корень, режим, входы и пути обмена; не переписывай туда вместо файла всё задание. Новый контекст не подменяется продолжением прежнего агента.

| Инструмент | Исполнение | Ревью |
|---|---|---|
| Claude Code | claude -p --model <модель> --permission-mode acceptEdits | claude -p --model <модель> --permission-mode plan; разрешены только нужные инструменты чтения/проверок |
| Codex | codex exec -m <модель> -s workspace-write | codex exec -m <модель> -s read-only -o <путь заключения> |
| Antigravity CLI | agy -p --model <идентификатор> --mode accept-edits --effort <уровень> | agy -p --model <идентификатор> --mode plan --output-format json |

Перед использованием сверяй `--help`, `--version`, путь executable, отдельный код выхода и реальный ответ. Наличие CLI или расширения не доказывает доступ к модели. Авторизацию и настройки разрешений ради обхода отказа не меняй; секреты не читай и не публикуй. Флаги обхода подтверждений и песочницы не используются.

В Windows PowerShell закрывай stdin: `$null | <CLI> ...`. Сохраняй stdout и stderr отдельно, а код CLI сразу после его завершения; последующая команда его не заменяет. Отчёты записываются UTF-8 без BOM через явный UTF8Encoding; не полагайся на кодировку `>` или версии PowerShell. Для JSON сохраняй только содержимое result/response в заключение, сохранив метаданные и ошибку отдельно. При ненулевом коде сохранённый файл не является успешным отчётом.

Внешний ревьювер возвращает полное заключение итоговым ответом; инструмент/оркестратор сохраняет его без правки. До и после вызова сравни SHA-256 spec.md, result.md и проверяемых файлов. Чтение установленного комплекта вне workspace должно быть реально разрешено; при отказе назови действие и причину, не расширяй режим. Шаблон промпта: «Выполни независимое ревью прямо сейчас за один запуск по <SKILL.md>, <входам> и <критериям>. Только чтение. Выбери вердикт по фактам. Верни заключение по форме навыка».

Python `.venv` может ссылаться на внешний базовый interpreter: для разрешённого Codex-вызова используй `--add-dir` с `home` из pyvenv.cfg, если требуется этой песочницей. Недоступные CLI сначала проверяются по известному пути установки; настройка shim выполняется только в рамках порученного подключения.

На Windows известные пути проверки: `%LOCALAPPDATA%/OpenAI/Codex/bin/*/codex.exe`, `~/.gemini/bin/agy.exe`; shims при порученном подключении — `~/.local/bin/codex.cmd`, `~/.local/bin/agy.cmd`. Проверяй текущую установку, а не предполагай существование бинарника по этому шаблону.
