# Подключение проекта

В проекте достаточно `AGENTS.md` и `orchestrate_workflow/method.md`; общие навыки устанавливаются отдельно и не копируются в проект. План создаётся по требованию, не при статусном запросе.

Штатные пути:

| Назначение | Путь |
|---|---|
| Привязка | `orchestrate_workflow/method.md` |
| Очередь | `orchestrate_workflow/plans/<план>/00_summary.md` |
| Материал | `orchestrate_workflow/plans/<план>/<задача>.md` |
| Текущая сессия | `orchestrate_workflow/<план>/spec.md`, `result.md`, `review.md`, `review_plan.md` |

Каталог плана в `plans/` версионируется. Каталог текущей сессии исключается по точному пути через `git rev-parse --git-path info/exclude`; незаконченные отчёты не стираются при повторном подключении. Имя `plans` зарезервировано.

## Определения ролей

Для Codex: `.codex/agents/<роль>.toml` с `name`, `description`, `developer_instructions`. Для Claude: `.claude/agents/<роль>.md` с frontmatter и путём установленного навыка. Для Antigravity: `.agents/agents/<роль>.md` или `~/.gemini/config/agents/<роль>.md` с `name`, `description`, `subagent: true`, поддерживаемой моделью и проверенным `tools`.

Тонкий адаптер сообщает агенту: «Прочитай установленный SKILL.md своей роли, AGENTS.md, method.md и заданные пути; действуй только в разрешённой границе». Не копируй протокол в определение. Если модель и effort хоста не совпадают с требуемыми, не используй неконтролируемое `inherit`; вызови роль через совместимый CLI. Наличие файла без реального обнаружения не доказывает подключение.

## method.md

```markdown
# Привязка проекта <имя>

## Пути
<Только отклонения от штатных путей>

## Предметный контракт
<Точные документы, команды, ресурсы и дополнительные критерии>

## Профили и ограничения
<При необходимости закреплённые поставщики, модели, runtime,
режимы разрешений и ограничения; иначе «по общему протоколу»>

## Формат отчёта
<Только если у проекта есть собственные требования>
```

Не дополняй привязку вымышленными путями и правилами. Пользовательские настройки и существующие определения ролей сохраняй. Примеры в `examples/` предназначены для адаптации, а не слепого копирования.
