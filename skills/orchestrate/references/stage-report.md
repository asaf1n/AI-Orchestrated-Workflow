# Итог работы

Каждый ответ начинай с того, **что сделано**, затем **следующий шаг**. После них — при необходимости проверки и блокер, коммит или ссылка.

Называй сущности по смыслу: план, задача, роль, проверка. Идентификаторы, пути, имена моделей и псевдонимы в коде — только дополнительно, если они нужны читателю.

Не копируй журналы вызовов, полные результаты тестов и отчёты ролей без запроса. Формат отчёта, установленный целевым проектом, имеет приоритет.
